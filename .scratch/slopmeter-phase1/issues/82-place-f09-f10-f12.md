# Place F09, F10 and F12 on the map

Type: grilling
Status: open
Blocked by: 

## Question

The spec's function catalog has three warn rules that its phase plan never assigns: F09 constructs an I/O dependency inline (`open(...)`, an HTTP or database client, per-language type list), F10 a void function mutates an argument, and F12 a null literal returned or passed (`None`, `nullptr`, `NULL`; the spec turns it off for Go). The map carries none of them in its fog or its out-of-scope list, and `rules::evaluate` has no warn other than F03 and F07. Decide for each whether it ships in this effort as a warn with the spec's fixed weight, waits for a later effort, or is dropped, and for any that ships, what the Python, Rust and C++ adapters can detect without symbol resolution (F10 in Rust is `&mut` on a parameter of a function that returns `()`; F12 in Rust has no null). A build slice per shipped rule follows.
