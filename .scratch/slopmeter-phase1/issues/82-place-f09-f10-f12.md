# Place F09, F10 and F12 on the map

Type: grilling
Status: resolved
Blocked by: 

## Question

The spec's function catalog has three warn rules that its phase plan never assigns: F09 constructs an I/O dependency inline (`open(...)`, an HTTP or database client, per-language type list), F10 a void function mutates an argument, and F12 a null literal returned or passed (`None`, `nullptr`, `NULL`; the spec turns it off for Go). The map carries none of them in its fog or its out-of-scope list, and `rules::evaluate` has no warn other than F03 and F07. Decide for each whether it ships in this effort as a warn with the spec's fixed weight, waits for a later effort, or is dropped, and for any that ships, what the Python, Rust and C++ adapters can detect without symbol resolution (F10 in Rust is `&mut` on a parameter of a function that returns `()`; F12 in Rust has no null). A build slice per shipped rule follows.

## Answer

Resolved 2026-10-29 with Christopher. The three ship as weight-1 warns only where they apply: F09 in all three languages from a per-language name list with a config `allow`; F10 in Python and C++ and not Rust; F12 in C++ only. F10 and F12 take no config key, and a waiver for any of the three fails the run. [ADR 0036](../../../docs/adr/0036-three-warns-where-they-apply.md). The build slices are [87](87-score-f09.md), [88](88-score-f10.md), and [89](89-score-f12.md).

## Comments

2026-10-29 — The three rules ship as warns at weight 1, each only where it applies: F09 in Python, Rust and C++ from a per-language name list of constructors and connect calls; F10 in Python (assignment to a parameter's attribute or index, or a known mutator called on a parameter) and C++ (a non-const reference or pointer parameter on a `void` function), not Rust, where `&mut` on a `()` function is the idiom; F12 in C++ only, since Rust has no null and `None` is Python's own idiom. The name lists and the mutator list are build-ticket detail.

2026-10-29 — F09 takes a per-language `allow` key like F08's, and each added name is a departure note. F10 and F12 take no key. A waiver line for any of the three fails the run.
