F05  nesting

A reader should not hold three levels at once.

Counting
Nesting is the deepest structural level. An if, a loop, a match or
switch, a ternary, and a catch each add one inside the body or a
ternary's value operand. A condition, an else, an elif, an else if, a
boolean operator, a lambda, a guard, a comprehension clause, a try, a
finally, a with, and a #if add none. Handlers on one try share one
level, and so do the arms of one match and the cases of one switch. A
structural form inside a lambda counts on the enclosing function. A
nested function's nesting stays on that function. A function with none
of these has nesting 0. The finding is that depth, at the deepest of
these lines, and at the earlier line when two share that depth.

Threshold
Shipped stand-in: gate at 3 in every language. 3 passes
and 4 fails.
No warn level.
A contiguous `# slopmeter: waive <RULE> <NUMBER> <REASON>` run directly
above the function excuses this gate in Python, and the same tokens
after `//` do so in Rust and C++, with a whole number except on F02,
which may be fractional.

Before
def pick(rows, flag):
    for row in rows:
        if flag:
            if row.ok:
                return row

After
def pick(rows, flag):
    if not flag:
        return None
    for row in rows:
        if row.ok:
            return row

Anti-fixes
Indenting the inner condition less leaves the depth in place.
A blank line between the levels does not lower the depth.
Moving the inner form into a lambda here still counts it.
