# Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `slopmeter` crate whose in-memory IR can hold one scored file and its functions, with a CI job that fmt-checks, clippy-denies warnings, and runs the tests.

**Architecture:** One crate. `src/lib.rs` exports the IR. `src/main.rs` is an empty binary until the reporter session. Later sessions add `inputs`, `adapters`, `analyzers`, `rules`, and `reporters` as modules. The Python validation milestone is sessions 2–13 below. Rust and C++ are sessions 14 and 15. This file's tasks are session 1 only. Each later session is one wayfinder ticket and gets its own code-level plan when that ticket is taken, against the acceptance test named here.

**Tech Stack:** Rust stable, edition 2021, `cargo` test / fmt / clippy. Tree-sitter arrives with the Python adapter, not in this session.

## Global Constraints

- One crate, named `slopmeter`. Modules, not a workspace. Grammars are dependencies when an adapter needs them.
- The IR stays in memory. No version field. No config hash in the report.
- A file record has a repo-relative path, one language, an unparsed ratio, and functions in source order.
- A function has `name`, `param_types`, `qualifier`, body span, touch span, `params` (`name`, `receiver`), and a body: `lloc`, `decisions` (`line`, `depth`), `cognitive` (`line`, `kind`, `depth`), `chains` (`line`, `rooted`, `members` of `name` and `call`), and `forward` (`line`, `names`) or none.
- Cognitive kinds are `structural` (sum 1 + depth), `hybrid` (sum 1), and `fundamental` (sum 1).
- Spans are inclusive line numbers. No columns.
- CI on push to `main` and on pull requests is `cargo fmt --check`, `clippy` with warnings denied, and `cargo test`, on stable.
- F03, F07, and F08 are the only rule ids whose metrics are already decided. Which metric F01, F02, F04, F05, F06, and F11 measure is [Which metric each rule id measures](../../.scratch/slopmeter-phase1/issues/34-rule-ids.md). Do not guess it in an earlier session.
- Shipped threshold numbers are stand-ins until the validation run. A gate is not switched off to make a clean repo pass.

```rust
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Language {
    Python,
    Rust,
    Cpp,
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct Span {
    pub start: u32,
    pub end: u32,
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Param {
    pub name: String,
    pub receiver: bool,
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Decision {
    pub line: u32,
    pub depth: u32,
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum CognitiveKind {
    Structural,
    Hybrid,
    Fundamental,
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Cognitive {
    pub line: u32,
    pub kind: CognitiveKind,
    pub depth: u32,
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Member {
    pub name: String,
    pub call: bool,
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Chain {
    pub line: u32,
    pub rooted: bool,
    pub members: Vec<Member>,
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Forward {
    pub line: u32,
    pub names: Vec<String>,
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Body {
    pub lloc: u32,
    pub decisions: Vec<Decision>,
    pub cognitive: Vec<Cognitive>,
    pub chains: Vec<Chain>,
    pub forward: Option<Forward>,
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Function {
    pub name: String,
    pub param_types: Vec<String>,
    pub qualifier: String,
    pub span: Span,
    pub touch: Span,
    pub params: Vec<Param>,
    pub body: Body,
}

#[derive(Clone, Debug, PartialEq)]
pub struct File {
    pub path: String,
    pub language: Language,
    pub unparsed_ratio: f64,
    pub functions: Vec<Function>,
}
```

## Later sessions

Each session is one ticket. Its code-level plan is written when the ticket is taken. The acceptance test is the bar.

2. **Source selection** ([Select the scored files](../../.scratch/slopmeter-phase1/issues/29-source-selection-build.md)). `inputs::select(root) -> Vec<Selected>` returns repo-relative paths. A fixture tree with `src/a.py`, `tests/test_a.py`, `target/b.rs`, and `foo.pb.cc` yields only `src/a.py`. `build.rs` is kept. `--tests` on the same tree also yields `tests/test_a.py`.
3. **Config** ([Load slopmeter.toml](../../.scratch/slopmeter-phase1/issues/30-config-loader.md)). `inputs::load_config(root) -> Result<Config, ConfigError>`. A missing file is the built-in. `coverage`, `include`, `exclude`, `[profile.python.F03] gate`, and `[profile.rust.F08] allow` parse. An unknown key, an empty `include`, and `gate` below the built-in `warn` return the error. The built-in warn and gate numbers for rules other than F03, F07, and F08 wait on the rule-id ticket. Until then the loader accepts `warn` and `gate` on `F03` only, plus `allow` on `F08`.
4. **Python functions** ([Parse Python functions](../../.scratch/slopmeter-phase1/issues/31-python-functions.md)). `adapters::python::parse(path, source) -> File`. A fixture with a nested `def`, a lambda inside a function, and a lambda bound to a name yields two functions. The nested body is its own function. The inner lambda is not. `tree-sitter` 0.27.1 and `tree-sitter-python` 0.25.0.
5. **Python classification** ([Classify a Python body](../../.scratch/slopmeter-phase1/issues/32-python-classification.md)). The same `parse` fills `lloc`, `decisions`, `cognitive`, `chains`, and `forward` for one fixture function that has an `if`, an `else`, a boolean run, a closure with a `let`-equivalent statement, and a one-line forward. Counts match [ADR 0003](../../docs/adr/0003-cyclomatic-complexity-rules.md), [ADR 0020](../../docs/adr/0020-cognitive-complexity-increments.md), and [ADR 0021](../../docs/adr/0021-logical-line-is-a-statement.md).
6. **Analyzers** ([Derive the measurements](../../.scratch/slopmeter-phase1/issues/33-analyzers.md)). `analyzers::measure(file) -> Vec<Measurement>`. Cyclomatic complexity is 1 plus the decision count. Cognitive complexity is the sum from the kinds. Nesting is the deepest decision depth, or 0. Parameter count excludes the receiver. Chain depth drops allow-list names supplied by the caller. The forward ratio is forwarded ordinary names over ordinary parameters.
7. **Rule ids** ([Which metric each rule id measures](../../.scratch/slopmeter-phase1/issues/34-rule-ids.md)). A decision, not code. F03, F07, and F08 stay as already decided.
8. **Rule engine** ([Turn measurements into findings](../../.scratch/slopmeter-phase1/issues/35-rule-engine.md)). `rules::evaluate(measurements, profile) -> Vec<Finding>`. One finding per rule per function, at the worst site. F07 is warn-only at 80. F08 is gate-only at the depth it crossed. Stand-in thresholds live in the built-in profile.
9. **Reporters** ([Print the table and the JSON report](../../.scratch/slopmeter-phase1/issues/36-reporters.md)). `reporters::render(report, json: bool) -> Rendered`. The text matches `prototype/text-output/table.txt` for that fixture. `--json` emits the document and no table. Exit 0, 1, and 2 follow [ADR 0019](../../docs/adr/0019-text-table-and-explain.md).
10. **Diff scope** ([Gate touched functions](../../.scratch/slopmeter-phase1/issues/37-diff-scope.md)). A fixture git repo with one changed line puts that function in `findings` and another over-threshold function in `inherited`. `--strict` puts both in `findings`.
11. **LCOV and CRAP** ([Join coverage and compute CRAP](../../.scratch/slopmeter-phase1/issues/38-lcov-crap.md)). `inputs::read_lcov(path) -> Coverage`. A function's fraction is hit `DA` lines over `DA` lines in its body span. No report leaves CRAP unset and adds the run-level note. `--coverage` replaces the file key.
12. **Explain command** ([Print one explain page](../../.scratch/slopmeter-phase1/issues/39-explain-command.md)). `slopmeter explain F08` prints the page and exits 0. `explain F09` exits 2. The page states the shipped threshold. The nine pages of words are [Author the nine explain pages](../../.scratch/slopmeter-phase1/issues/27-explain-pages.md), which is blocked until the rule ids exist.
13. **Fixtures and the CC cross-check** ([Lock the reporters and the CC delta](../../.scratch/slopmeter-phase1/issues/40-fixtures-and-cross-check.md)). One fixture file per rule. Golden files for the table and the JSON report. A Python CC fixture records the delta against radon on the constructs [ADR 0003](../../docs/adr/0003-cyclomatic-complexity-rules.md) already lists.
14. **Python validation** ([Run the Python corpus](../../.scratch/slopmeter-phase1/issues/41-python-validation.md)). `--strict` on the three pinned Python repos. Thresholds move until there is no gate finding. The sloppy tree is pinned once it gates the gating rules and warns on F07. The nine-repo run is not added to CI.
15. **Rust** ([Rust adapter and its validation run](../../.scratch/slopmeter-phase1/issues/42-rust-adapter.md)). `adapters::rust::parse`, grammar `tree-sitter-rust` 0.24.2. The pipeline does not gain a language match outside the extension arm. Then the Rust corpus.
16. **C++** ([C++ adapter and its validation run](../../.scratch/slopmeter-phase1/issues/43-cpp-adapter.md)). `adapters::cpp::parse`, `tree-sitter-cpp` pinned to `c009222808634c1014f82438d4883753516a2c24`. Both `#if` arms are scored. A literal `#if 0` is dropped. Then the C++ corpus.
